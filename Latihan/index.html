Testimoni

Mata kuliah Desain Web memberikan banyak pengalaman baru bagi saya. Sebelumnya saya hanya tahu web sebagai halaman yang dibuka di browser, sekarang saya paham bagaimana halaman tersebut disusun mulai dari HTML, diberi tampilan dengan CSS, dibuat interaktif dengan JavaScript, hingga dibuat lebih cepat dengan Bootstrap.

Materi disampaikan secara bertahap sehingga mudah diikuti. Setiap modul dilengkapi praktikum dan latihan yang langsung dikerjakan, jadi teori yang dipelajari bisa langsung dicoba dan hasilnya terlihat di browser.

Bagian yang paling saya sukai adalah responsive web design dan Bootstrap, karena saya bisa membuat tampilan yang rapi di laptop maupun di HP tanpa harus menulis banyak kode CSS dari awal.

Kritik

Beberapa contoh kode pada modul masih memakai versi lama, misalnya atribut data-toggle dan class form-group dari Bootstrap 4, sehingga perlu disesuaikan lagi agar berjalan di Bootstrap 5. Selain itu, potongan kode pada modul kadang terpotong atau spasinya hilang sehingga sulit disalin.

Saran

Contoh kode pada modul sebaiknya diperbarui mengikuti versi Bootstrap terbaru dan disediakan juga dalam bentuk file agar mudah dicoba. Akan lebih baik lagi jika ada satu proyek kecil yang dikerjakan dari modul awal hingga akhir supaya materi terasa saling terhubung.
